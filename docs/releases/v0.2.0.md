# Torio v0.2.0

## Highlights

### Honest partial-provisioning reports

`torio mcp install` now preserves durable `changed` and `restart_required`
state when a later provisioning or verification step fails. Human and JSON
errors report the partial effect without claiming that the dormant broker was
installed or activated.

### MCP custody is documented as a boundary, not a working integration

The operator documentation now includes `torio mcp install` and `torio mcp
status`. These commands provision and verify the dedicated `torio-mcp` guest
identity, private home, client group, and root-owned policy directory.

This release does not package or activate the broker daemon or relay. It does
not perform OAuth and does not carry upstream MCP traffic. ADR-0027 remains the
delivery boundary.

### Multi-service write-window spike

The repository includes an isolated Go spike covering service-agnostic policy,
time-bounded per-service writes, destination binding, bounded and redacted
audit, OAuth custody and refresh serialization, fail-closed filesystem state,
and bounded upstream and downstream I/O.

The spike includes local fixtures and a public Atlassian metadata-only probe.
Its verdict remains `PARTIAL`. The probe stops before browser authorization,
token issuance, content access, or write, and the spike is not wired into the
released CLI or packaging.

### Deterministic release archive modes

Release packaging now records the CLI as `0755` and both text files as `0644`,
regardless of the source checkout's modes. This avoids a release README that is
readable only by the account that created the archive.

## Upgrade

Download the release assets with a GitHub client that already has repository
access, then let the installer verify `SHA256SUMS`:

```bash
gh release download v0.2.0 -D /tmp/torio-rel
scripts/install.sh --version 0.2.0 --base-url file:///tmp/torio-rel
```

Confirm the installed build:

```bash
torio version
```

`torio project shell` still forwards the Mac SSH agent only for the active
operator session. The persistent Hermes service receives no forwarded agent
socket, and Torio performs no automated push, merge, tag, or release.
