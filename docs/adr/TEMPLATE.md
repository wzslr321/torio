# ADR-NNNN: One sentence stating the decision

- Status: Accepted
- Date: YYYY-MM-DD
- Applies to: the packages and documents this decision governs
- Invalidates: ADR-NNNN P1 (only when a premise below makes an earlier one false)
- Supersedes / Superseded in part by: (only when replacing a decision)

## Decision

**The decision, in at most ten lines, written so a reader can stop here.**
State what is now true and what is now forbidden. Do not motivate it here;
that is what Context is for.

### Premises

- P1. A falsifiable statement about the world this decision depends on.
- P2. Another. One line each. If it can never be proven false, it is not a
  premise, it is a slogan; cut it.

## Walkthrough

Required when the decision changes an operator surface, otherwise omit the
section. What the operator does, in order, at the keyboard: before the change,
after the change. If the sequence reads worse after, the decision is wrong or
the walkthrough is dishonest; fix whichever it is before acceptance.

## Context

Why this came up, and only that. The reader already has the decision.

## Consequences

What gets worse, who pays, and what this commits future work to. A consequence
nobody would object to is padding; cut it.

## Rejected

Each alternative that was seriously considered, with the reason it lost.
These are how a reader tells a decision from a default. One paragraph each.
