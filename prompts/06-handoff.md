# Zadanie: przygotuj handoff po sesji

Nie implementuj nowej funkcji. Zweryfikuj aktualny stan repo i przygotuj zwięzły handoff dla następnego LLM-a.

Wymagany format:

```text
Goal
Completed behavior
Real verification commands + exit codes
Changed files
Decisions/contract changes
Security invariants checked
Known failures/blockers
Uncommitted state
Exact next task (one slice)
Files to read first
```

Nie zapisuj transient handoffu do persistent memory. Jeśli task nie przeszedł testów, oznacz go FAILED/BLOCKED i nie zaznaczaj planu jako completed. Nie wymyślaj wyników komend, których nie uruchomiono.
