# Brain operating rules

- Write concise Markdown and keep one topic per file.
- Capture uncertain destinations in `inbox/`, then route them deliberately.
- Use relative links for notes and local attachments.
- Search before creating a note; update the existing source instead of
  duplicating it.
- Never store passwords, tokens, private keys, recovery codes, or other secrets.
- Do not copy note content into logs, public issues, or code repositories.
- Preserve useful existing structure when editing.
