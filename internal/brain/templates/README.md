# Second Brain

This is a private, Markdown-first workspace for notes, decisions, and follow-up.

## Layout

- `inbox/` — capture first; route each item when its destination is clear.
- `daily/` — brief daily notes.
- `projects/` — one file per active project or outcome.
- `people/` — one file per person, with only appropriate context.
- `meetings/` — meeting notes and follow-up.
- `resources/` — durable reference notes.
- `attachments/` — local files referenced by relative links.
- `todo.md` — current actions.

Use concise Markdown, keep one topic per file, and link with relative paths (for
example, `resources/example.md`). Update an existing note instead of creating a
duplicate.
