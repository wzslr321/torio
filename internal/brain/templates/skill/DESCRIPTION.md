# Brain

Torio installs this category so the Second Brain retrieval skill has somewhere
to sit that is not the top level of the skills tree.

Hermes renders the `description` above into the skill index of every session,
and — unlike a skill's own description, which is truncated at 60 characters —
it is not capped. That is the reason this file exists: it is the only place in
the index with room to say that the vault is private, that retrieval is
targeted, and that it must never be read in bulk.

Only the frontmatter is read. This body is for whoever opens the file on the
guest.
