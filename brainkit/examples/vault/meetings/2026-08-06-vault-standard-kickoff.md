# Vault standard kickoff

With [Jane Doe](../people/jane-doe.md), on
[vault standard](../projects/vault-standard.md).

## Notes

- Walked the eight note types. Jane's objection: a required field per type
  reads as rigour and behaves as rot, because the field is filled in once and
  never corrected.
- Wikilinks came up twice. The portability argument did not move anyone; the
  verifiability one did.
- Agreed the sample vault has to be a real fixture, not prose about a fixture,
  or the examples drift from the standard within a month.

## Decisions

- `type` is the only required field.
- Relative Markdown links only.
- The sample vault is the link target for the standard's examples.
