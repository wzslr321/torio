# Examples

[`vault/`](vault/index.md) is a complete, tiny Torio vault: one note per type,
linked the way [the standard](../STANDARD.md) says they should be.

It has three jobs.

1. **It is what the standard's examples point at.** Every "Example:" line in
   `STANDARD.md` links a real file here, so a link checker catches an example
   that stops matching the text it illustrates.
2. **It is the fixture the skills are exercised against.** Copy it somewhere
   scratch and run the commands at it — never at a vault with anything real in
   it.
3. **It is a starting point.** Copying it into an empty vault is a reasonable
   alternative to running `/brain-kit:init`, if you would rather read the shape
   than have it created for you.

Jane Doe is invented, and so is everything attributed to her.
